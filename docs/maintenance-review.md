## 已修正

- README 與中英十課教程以日常訊息、攝影學習資料為例；新手 CLI 不需 SDK、MCP 或 skill。SDK 範例另列依賴。
- `jev-workflow` 從安裝型 skill 改為普通整合指南；歷史 A/B 記錄保留但撤回「一次比較證明必要」的結論。
- CLI 修正旗標解析、非法值、輸入衝突、空測試集、缺漏答案、字串布林標籤；doctor 失敗回傳非零；批次改為受控併發與請求逾時。
- `filter --only-kept` 輸出可供下一步使用的原始資料；報告資料安全嵌入，避免 `</script>` 與 replacement 字串造成 HTML 注入或內容損毀。
- observe 範例真的執行並輸出一致的 JSONL 格式；usefulness 可保存答案後用 `--reuse` 離線重排，並核對資料與問題指紋。
- setup 僅安裝專案依賴；驗證腳本不清空舊紀錄、不在整套檢查失敗時覆寫 expected；數值比較保留同筆資料與欄位對應。
- 移除固定速度保證、伺服器快取推論、通用 fail-open、confidence 等於準確率，以及「所有範例都已通過」等過度敘述。
