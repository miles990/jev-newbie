# 用機率做模擬：前提要說清楚

```sh
npm ci
node examples/js/monte-carlo.mjs
```

範例用十二則訊息的模型分數，在程式裡模擬不同門檻、比較假設成本，並對少量標籤做 bootstrap。它不會真的刪除或回覆訊息。

必須區分三件事：模型機率、模型假設下的模擬結果、真實世界觀測。模擬不是額外證據，不能自行修正模型錯誤。

目前範例把詐騙與期待回覆當成獨立 Bernoulli 變數抽樣；兩者可能相關。結果只在該獨立性與機率校準假設下成立。假設成本是教學選值，不是已量測的損失。

八筆案例全對時，普通 bootstrap 可能得到 100%–100% 區間。這不表示母體零錯誤，而是小樣本重抽無法產生沒觀測到的錯誤。需要更多獨立資料與合適的區間估計。

本範例每次執行都重新呼叫 Jev；固定亂數種子只讓相同機率下的抽樣可重現。
