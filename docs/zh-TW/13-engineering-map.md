# Jev 與其他工程方法：一張地圖

把 Jev 剝到只剩本質：**一個便宜、快速、校準過的文字語意判斷預言機。** 給它 state 與封閉問題；一秒內回你機率、帶分布的標籤、或尺度上的位置，花不到一美分，而且一致。

這一句話就決定了它怎麼跟其他東西結合。任何**消耗**機率、標籤或分數的工程方法，現在都能消耗一個*關於文字的*。任何**產生**候選、狀態或假設的方法，都能幾乎免費地讓它們*被判*。任何建立**真相**的方法（測試、證明、量測、人），留在原地，Jev 站在旁邊。

## 三條接縫

| 接縫 | 跨過去的東西 | 例子 |
| --- | --- | --- |
| 文字變數字 | Jev 的機率、標籤、分數成為輸入 | 統計、決策理論、控制迴圈、ML 特徵、訊號處理 |
| 對候選做判斷 | 其他方法產生的東西得到型別化判決 | 搜尋、最佳化、LLM 生成、規劃、檢索 |
| 真相留在別處 | Jev 分流、標記、路由；不做決定 | 測試、編譯器、感測器、算術、法律、醫療、人 |

## 逐學科的地圖

| 學科 | 它的方法 | Jev 接在哪 | 它不取代什麼 |
| --- | --- | --- | --- |
| **決策理論** | 期望效用、錯誤代價 | 每項校準的 `p` × 你的成本表 → 期望成本最低的動作；三段門檻隨代價變 | 成本表；高風險動作的決定 |
| **統計** | 假設檢定、信賴區間、bootstrap、校準 | Jev 的答案就是樣本；對黃金測試集 bootstrap；在你的資料上驗校準；模擬用的逐項 Bernoulli 參數 | 算術；顯著性判斷 |
| **Monte Carlo／模擬** | 抽樣世界、傳播不確定性 | Jev 給一次逐項機率；程式碼抽一萬次 | 抽樣本身；任何 Jev 絕不該「數值估計」的東西 |
| **控制理論** | 回饋、設定點、觀測器、安全包絡 | Jev 是慢速顧問型觀測器（2 到 10 Hz），替情境命名；快速決定性迴圈保留否決權；場景指紋避免重問 | 控制器；安全反射 |
| **最佳化與搜尋** | 爬山、beam search、MCTS、演化迴圈 | Jev 是便宜的目標函數或政策先驗：每輪對每個候選打分；單調接受；無進步即停 | 搜尋演算法；終止邏輯；存在時的真實目標函數 |
| **機器學習** | 特徵工程、主動學習、集成、蒸餾 | 每題是一個語意特徵欄位；分歧或低信心挑下一批要標的；Jev 特徵訓練傳統模型，之後免費跑 | 模型訓練；特徵選擇的統計 |
| **資訊檢索** | BM25、embedding、reranker、RAG | 第一階段檢索用程式碼或 embedding；Jev 重排短清單、分類段落、丟掉被注入的指令 | 索引；精確比對 |
| **訊號處理** | Fourier、自相關、變點偵測 | Jev 把文字流變成隨時間的數值序列；程式碼找週期；Jev 解讀具名結果 | 轉換本身 |
| **軟體工程** | 型別、測試、CI 關卡、契約、code review | Jev 是可放進關卡的型別化述詞：「這個 diff 涵蓋宣稱嗎」「這個 PR 有風險嗎」「agent 做完了嗎」；黃金測試集是它的單元測試；`--strict` 讓 CI 失敗 | 編譯器、測試套件、語法層的 linter |
| **可靠性工程** | 失敗放行、斷路器、shadow 模式、SLO、金絲雀 | 每個 Jev 關卡遇 429／逾時放行；先 shadow 再上線；每次呼叫記錄；像依賴一樣釘模型版本 | 事故處理；決定性規則 |
| **排隊與作業研究** | 分流、優先、路由、容量 | 每項的意圖與急迫度餵給排隊紀律；期望成本路由；低信心升級 | 排隊的數學 |
| **形式方法** | 不變量、契約、斷言 | Jev 不給不變量；恆等式由程式碼強制（模型不保證 `p(A) + p(¬A) = 1`）；型別化輸出保證形狀，不保證真相 | 證明；schema 驗證 |
| **人因／HCI** | 升級、可解釋性、信任校準 | 信心分段決定何時給人看；機率顯示而非隱藏；可讀的特徵名取代 embedding | 用文字解釋（LLM 或人寫） |
| **資安** | 允許清單、威脅模型、縱深防禦 | 對每次工具呼叫與回傳做語意檢查：破壞？外洩？prompt injection？多層中的一層，絕不是唯一 | 硬規則；密鑰處理；授權 |
| **經濟學** | 資訊的成本、邊際價值 | 每次判斷 0.00002 美元，「什麼都問」是理性的；昂貴的一步（LLM、視覺、人）只花在 Jev 說值得的地方 | 昂貴一步的預算 |
| **實驗設計** | 黃金測試集、留出、A/B、消融 | 相信門檻前先標二三十筆真實資料；對任何提案者留出；拿掉一題整批重跑只花幾美分 | 實驗的結論 |
| **知識與本體工作** | 分類法、實體解析、對齊 | 把 `other` 經 LLM 迴圈長出類別清單；問「同一實體嗎」三種結果做記錄對齊 | 替新類別命名；最終合併決定 |
| **感知（視覺、聲音）** | 偵測器、OCR、語音辨識、VLM | 變成文字之前什麼都不做；之後 Jev 結構化發現、在候選中挑選、替昂貴呼叫設關卡 | 看與聽 |
| **生成式 AI／agent** | LLM、工具使用、多 agent | Jev 在前（路由、守門）、在內（prompt 裡的型別化事實）、在後（驗證、重試）、在周圍（壓縮、喚醒關卡、skill 選擇） | 生成；命名；解釋 |

## 結合換來什麼，各一句

- **便宜到什麼都能問**，所以過濾器移到昂貴步驟前面，而不是後面。
- **快到能進迴圈**，所以評估進到迭代裡面，而不是最後。
- **校準到能拿來算**，所以機率流進期望成本、模擬、特徵，而不是門檻切一次就丟。
- **型別化到能測試**，所以一個判斷變成單元測試、CI 關卡、綁 schema 的欄位。
- **一致到能比較**，所以指標的變化代表輸入變了，不是雜訊。

## 它不改變什麼

真相的裁判。測試仍然測，編譯器仍然編，感測器仍然量，人仍然決定需要人的事。Jev 接手的是那些過去靠正規表達式、關鍵字表、手調常數或第二個 LLM 的語意述詞，把它們變便宜、可量測、對自己的不確定誠實。那是很大的一片；不是工程的全部，而這個工具包的設計就是為了把這條線畫清楚。
