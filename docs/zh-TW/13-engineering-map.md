# 進階方法如何搭配

這頁提供延伸思路，不表示每種方法都已在本專案實作或驗證。

| 方法 | Jev 可提供 | 必須另做 |
| --- | --- | --- |
| 搜尋與排序 | 候選相關性、主題 | 取得資料、索引、排序與離線評估 |
| 決策分析 | 對文字的候選判斷 | 成本表、校準評估、動作政策 |
| 模擬 | 有條件的機率輸入 | 相關性假設、抽樣、真實結果驗證 |
| 機器學習 | 語意特徵欄位 | 標籤、訓練、留出評估 |
| 迴圈最佳化 | 某個可測量的代理指標 | 停止條件、預算、真正目標的驗證 |
| 軟體測試 | 對宣稱或輸出的輔助檢查 | 編譯、確定性測試、契約與證據 |
| 介面操作 | 候選元素與動作選擇 | 最新畫面、授權、執行與完成驗證 |

多個相關問題可以在一個請求裡回答；真正依賴前一步結果的動作仍要依序做。新增模型呼叫是否值得，需看省下的工作是否超過延遲、用量與誤判成本。

先完成[教程](../../tutorial/README.md)，再挑一個具體用途量測。[官方用例地圖](https://docs.typesafe.ai/concepts/use-case-map)可用來尋找方向。
