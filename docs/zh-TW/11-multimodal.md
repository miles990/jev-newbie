# 圖片與聲音如何搭配 Jev

Jev 在這個工具包使用的 API 接收文字與 JSON。圖片網址或 base64 只是文字，不能當成它看過影像。

```text
圖片／聲音 → OCR、視覺或語音工具 → 文字描述 → Jev 的多個問題 → 程式決定
```

例如會議逐字稿可以判斷「是否有待辦」「是否已做決定」「屬於哪個主題」。OCR 取得的候選文字可以交給 Jev 依背景選一個，但漏掉的文字或看錯的畫面仍是前段工具的限制。

可以根據檔名、說明做初步分流，但不要把後設資料的猜測當成內容驗證。數值、總額與日期仍由程式處理。

這頁是架構說明；本 repo 沒有附 OCR、語音或完整多模態應用。
