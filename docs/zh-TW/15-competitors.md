# 如何比較替代方法

不必先判斷誰是「直接競品」。先固定你的輸入、預期答案和限制，再比較做法。

| 做法 | 適合先試的情況 | 需要量測 |
| --- | --- | --- |
| 規則與查表 | 條件明確、資料結構穩定 | 維護成本、漏掉的語意案例 |
| 關鍵字或搜尋 | 詞彙穩定、需求簡單 | 同義改寫、誤中與漏中 |
| embedding／reranker | 候選搜尋、相關性排序 | 排名品質、延遲、語料覆蓋 |
| 監督分類器 | 已有標籤、固定類別 | 標註與訓練成本、分布變動 |
| LLM | 需要解釋、生成或多步推理 | 輸出格式、費用、耗時與準確度 |
| Jev | 可定義成多個封閉語意問題 | 正確率、覆核率、用量、延遲 |

本 repo 沒有做跨產品的公平基準。舊版文件的「沒有競品」「固定快幾倍」與無法在 repo 重現的百分比，不能作為選型依據。

同一批未參與調整的資料、相同任務與品質目標，才能比較。官方 [use-case map](https://docs.typesafe.ai/concepts/use-case-map)是用途索引，不是比較基準。

官方 skill、MCP 與本專案指南是使用方式或文件，不是不同的判斷模型。原 `jev-workflow` 的內容已整併到[AI 整合指南](16-agent-integration.md)，不再提供另一個需要安裝的 skill。
