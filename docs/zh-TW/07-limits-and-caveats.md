# 能力邊界與常見誤解

- **有選項不代表會選對。** 格式正確的答案仍可能是錯誤判斷。
- **信心不等於正確率。** Choice／Score 的 confidence 來自機率分布；不同任務要自己評估。
- **「其他」不是未知偵測保證。** 新情境也可能被分到舊類別。
- **同時多題不代表題目彼此能讀答案。** 每題讀同一份 state；如果第二題必須知道第一題真正的輸出，需下一次呼叫或程式合併。
- **模型不會自動上網查證。** state 裡聲稱是研究或官方通知，並不使它成真。
- **媒體網址不是媒體輸入。** 先用 OCR、語音辨識或視覺工具取得描述，再交給 Jev。
- **數學與日期交給程式。** 固定規則與精確 ID 不需要語意模型。
- **固定版本也不是逐位元一致保證。** 保留重跑差異、錯誤與費用紀錄。

較長輸入、更多題目、併發、速率限制與重試都可能增加費用或延遲。請以目前帳號限制及實測為準。英文或中文哪個更好，需在你的資料上比較。
