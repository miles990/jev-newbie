# 請 AI 助手協助整合 Jev

這是一份可以直接交給 coding agent 閱讀的指南，不是需要安裝的 skill。只想自己用指令的人，繼續看[教程](../../tutorial/README.md)即可。

可以這樣提出需求：

> 我想替訊息整理工具加入分類建議。請先比較現有方法和 Jev，用我的標註資料檢查效果，不確定的留給我覆核。回報準確率、覆核率、延遲與用量，並在我要求的範圍內整合。

## 給助手的工作順序

1. 明確定義要改善的行為，保留能確定計算或查表的部分。不是每段 if／else 都該替換。
2. 寫問題檔，一題一個語意判斷。同一份 state 上不互相依賴答案的問題可合併請求。
3. 準備人工標籤與保留評估資料，和原方法比較。不要把模型答案當標準答案。
4. 依錯誤代價設定執行、覆核、停止或原流程 fallback；API 故障不能一律放行。
5. 若要求實作，再加入版本設定、逾時、有限重試、必要的快取與紀錄。CLI 本身沒有通用快取。
6. 回報更動位置、測試與未驗證範圍，留下問題、案例與可重跑的指令。

官方 [TypeSafe skill](https://docs.typesafe.ai/agent-skill)可補充 API 與設計模式；不必為了這份指南安裝它或 MCP。

原 `jev-workflow` 沒有提供獨立執行工具，內容與教程重疊，因此已移為普通文件。這不影響你先前在電腦上自行安裝的副本；本專案不會自動修改其他位置。
