# 有停止條件的改進迴圈

[llm-then-jev-loop.mjs](../../examples/js/llm-then-jev-loop.mjs)從少量類別開始：Jev 分類，LLM 為尚未分類的訊息提新類別，程式重新評估並保留 `other`／低信心比例較低的一輪。

```sh
npm ci
node examples/js/llm-then-jev-loop.mjs
```

依賴與 LLM 金鑰同[上一頁](08-jev-with-an-llm.md)。最多五輪、十個類別，無改善就停止；最後一輪不再提出沒機會驗證的分類。

**停止不等於找到正確分類法。** `other` 比例降低也可能只是類別變寬、模型過度自信，不能作為準確率改善的證明。用獨立標註資料衡量錯誤、類別重疊與可用性。

這個範例保留最佳「指標」，不是保證每次提案單調改善或必然收斂到正確答案。重跑可能得到不同的分類與文字。
