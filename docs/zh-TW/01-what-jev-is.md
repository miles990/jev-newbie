# Jev 是什麼

Jev 接收文字或 JSON，以及你定義的問題，回傳是非機率、單選或程度分數。它適合需要理解文字意思、但結果能用固定欄位表達的工作。

| 問題型別 | 用途 | 回傳 |
| --- | --- | --- |
| `noul` | 是否需要回覆 | 「是」的機率 |
| `choice` | 訊息分哪一類 | 選項、完整分布、信心值 |
| `score` | 多急、多相關 | 有序等級的加權分數、分布、信心值 |

重要能力是同一份輸入可以一次問多題，服務並行評估，程式收到答案後決定哪些有用。這省去「先分類，再問下一題」的往返，詳見 [平行判斷](14-speed-and-computer-use.md)。

它不會生成回覆、替你抓網頁或直接看圖片。精確計算、日期、查表與執行动作仍由程式負責。高信心不等於已查證；未知輸入也可能被自信地分錯。

速度、價格和模型別名會變動，不用一個展示案例推估所有工作。問題和資料、模型版本、網路、重試都影響結果。

來源：[API](https://docs.typesafe.ai/api)、[信心值](https://docs.typesafe.ai/confidence)、[官方用例地圖](https://docs.typesafe.ai/concepts/use-case-map)。
