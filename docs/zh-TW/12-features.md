# 把文字變成可分析欄位

每個問題可以成為一欄：是否在問問題、是否提到截止時間、是否在推銷。同一則輸入一次回答多題，形成一列數值，再由統計或機器學習程式分析。

```sh
npm ci
node examples/js/features.mjs
```

範例輸出 `runs/features.csv`，並顯示與 `needs_reply` 標籤的相關性。只有五筆有該標籤，結果只供展示，不能據此宣稱某欄有效或無效。

- 記錄問題、模型與資料來源，避免數值失去意義。
- 分開探索資料與最後評估資料；反覆選特徵也會過度擬合。
- 下游模型部署時，若仍使用 Jev 特徵，新輸入仍需呼叫 Jev，並非自動變成零 API 成本。
- 相關性不等於因果。數值雖常落在 0–1，仍依下游模型決定是否需要標準化。

Fourier、相關係數、特徵值等數學運算由程式做。Jev 提供的只是從文字取得的候選訊號。
