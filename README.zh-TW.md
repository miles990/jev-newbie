# jev-newbie

[English](README.md) · **繁體中文**

**從一則日常訊息開始，學會用 Jev 判斷、分類和評分。**

這是一份給初學者的實作指南。你不需要先會寫程式；準備好執行環境後，可以直接複製指令、換成自己的文字，看看結果怎麼變。

## Jev 可以幫我做什麼？

假設你收到這則訊息：

> 星期六晚上一起吃飯嗎？可以的話，明天前回我一下。

你可以把訊息交給 Jev，再問一個明確的問題：

| 你想知道的事 | 怎麼問 Jev | 它會回傳什麼 |
| --- | --- | --- |
| 要不要回覆？ | 這則訊息是否需要我回覆？ | 「是」的機率 |
| 是哪種訊息？ | 從「邀約、廣告、取貨通知、其他」選一類 | 選出的類別與各類別的機率 |
| 有多急？ | 從「可以晚點、今天處理、立即處理」評分 | 程度分數與各程度的機率 |

**你提供文字、提出問題，Jev 回傳判斷。** 它不會自動回覆朋友或幫你處理事情。結果也可能判斷錯，所以先用自己看得懂、能確認答案的訊息練習。

## 第一次使用：準備三樣東西

1. **Node.js 20 或更新版本**：用來執行這個專案的指令。
2. **這個專案的檔案**：下載 ZIP 並解壓縮，或用 Git 下載。
3. **[TypeSafe API key](https://console.typesafe.ai)**：登入後取得的服務存取金鑰，讓指令能呼叫 Jev。請把它當作密碼保管。

開啟終端機（macOS 的「終端機」或 Windows 的 PowerShell），輸入 `cd `，接上解壓縮後的資料夾路徑。例如：

```sh
cd "Downloads/jev-newbie-main"
```

請換成你電腦上的實際位置。接著設定金鑰，把下面的 `貼上你的金鑰` 換成自己的 API key。

**macOS／Linux：**

```sh
export TYPESAFE_API_KEY="貼上你的金鑰"
```

**Windows PowerShell：**

```powershell
$env:TYPESAFE_API_KEY="貼上你的金鑰"
```

金鑰設定適用於目前的終端機視窗，重新開啟後需要再設定。接下來的練習只需 Node.js，不必先執行安裝腳本。每次判斷會把文字送到 TypeSafe 雲端服務，並產生 API 用量。

## 練習一：這則訊息需要回覆嗎？

在同一個終端機視窗貼上：

```sh
node bin/jev.mjs ask "這則訊息是否需要我回覆？" --text "星期六晚上一起吃飯嗎？可以的話，明天前回我一下。"
```

這行指令分成三部分：

- `node bin/jev.mjs`：啟動專案裡的 Jev 工具。
- `ask "這則訊息是否需要我回覆？"`：提出一個可以回答「是／否」的問題。
- `--text "……"`：放入你想讓它判斷的文字。

結果會顯示百分比，以及 `yes`（是）、`no`（否）或 `unsure`（不確定）。**百分比代表模型認為答案是「是」的機率，不是這句話的真實程度。** 工具目前把高於 65% 顯示為 `yes`、低於 35% 顯示為 `no`，中間則顯示 `unsure`。

試著只把訊息換成「謝謝你，東西已經收到了，不用回覆」，再跑一次，觀察結果如何改變。

## 練習二：把訊息分成幾類

```sh
node bin/jev.mjs pick "這則訊息屬於哪一類？" --options "邀約,廣告,取貨通知,其他" --text "您的包裹已送達門市，請於三天內取貨。"
```

`pick` 代表「從選項中挑一個」；`--options` 是你提供的類別，用英文逗號分開。結果會列出各類別的機率，並用箭頭標出選中的類別。保留「其他」，讓不符合前三類的訊息也有地方可放。

你可以改成「工作、家庭、購物、其他」，再換成自己的訊息試試看。**類別由你決定，不必照用範例。**

## 練習三：判斷事情有多急

```sh
node bin/jev.mjs rate "這件事需要多快處理？" --levels "可以晚點處理,今天處理,立即處理" --text "十分鐘後就要出門了，但還找不到家裡的鑰匙。"
```

`rate` 用來判斷程度；`--levels` 要從低到高排列。這個範例的三個程度依序是 0、1、2，結果越接近 2，代表模型判斷越需要立即處理。它也會顯示各程度的機率與對應文字。

## 回頭看剛剛的結果

```sh
node bin/jev.mjs view
```

這會產生一份 HTML 報告，通常會自動在瀏覽器開啟。若沒有開啟，可以自行打開專案中的 `runs/report.html`。你能看到成功判斷的文字摘要、問題、答案和耗時，方便比較換了文字或問法之後的差異。

**接下來，找三則你熟悉的訊息，先自己判斷，再看看 Jev 是否和你一致。** 如果不同，檢查問題是否清楚、選項是否足夠，再嘗試補上必要的背景。分數高也不保證答案正確。
