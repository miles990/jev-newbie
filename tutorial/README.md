# Learn Jev · 學會使用 Jev

從日常訊息開始，依序學會提問、補充背景、排序、批次處理和檢查結果。第一次使用請從第 0 課開始；不需要安裝 agent skill 或全域指令。第 5、8 課會用到 JavaScript 範例，頁面會提醒安裝依賴。

Start at lesson 0. Learn with everyday messages, then context, ranking, batches, and evaluation. No agent skill or global command installation is required. Lessons 5 and 8 introduce JavaScript examples and explain their dependencies.
