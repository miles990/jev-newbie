# 第 9 課：處理未知，以及請 AI 助手幫忙

你的選項只有「邀約、廣告、取貨通知」，卻收到學校通知。保留「其他」能提供一個出口，但模型仍可能自信地選錯類別。

```sh
node bin/jev.mjs pick "這是什麼訊息？" --options "邀約,廣告,取貨通知,其他" --text "下週校外教學，請家長於週一前交回同意書。"
```

檢查「其他」、低信心，以及抽樣覆核的結果，再決定是否新增「學校通知」。不能只靠低信心偵測所有未知輸入。

## 想接進自己的工具時

如果你會使用 coding agent，可以把 [AI 整合指南](../../docs/zh-TW/16-agent-integration.md)交給它，再說：

> 我想在訊息整理工具加入分類建議。請先評估是否需要 Jev，用標註範例比較效果；不確定的留給我覆核。先回報結果，再依我要求的範圍整合。

這是一份普通文件，**不用安裝 `jev-workflow` skill**。已經明確、穩定的分類表通常不需要換成模型；先找規則真的處理不好的語意問題。

## 你現在能做的事

你已經會提出問題、提供背景、批次處理、比較標準答案，以及查看紀錄。挑一個小用途，用自己的資料測它是否真的省事，再決定要不要整合。
