# 第 2 課：三種問題

「要不要回覆」「是哪一類」「有多急」是不同的問題，適合不同的輸出。

```sh
node bin/jev.mjs ask "需要我回覆嗎？" --text "週六聚餐，能來的話回我一下。"
node bin/jev.mjs pick "這是什麼訊息？" --options "邀約,廣告,取貨通知,其他" --text "包裹已送達門市，請於三天內取貨。"
node bin/jev.mjs rate "這件事需要多快處理？" --levels "可以晚點處理,今天處理,立即處理" --text "十分鐘後出門，但還找不到鑰匙。"
```

| 指令 | 用途 | 讀法 |
| --- | --- | --- |
| `ask` | 是／否 | 顯示「是」的機率 |
| `pick` | 從你的選項挑一個 | 顯示各選項機率、箭頭與信心值 |
| `rate` | 在有序程度上評分 | 三級依序是 0、1、2；分數可以介於兩級之間 |

`confidence` 不是正確率。例如 0.9 表示分布較集中，不能直接讀成「這次有九成會答對」。低信心可以當成需要覆核的訊號。

選項用英文逗號分隔。可能遇到不符合的輸入時，保留「其他」。評分等級要從低到高排列，而且每級要有清楚含義。

練習：把分類改成「工作、家庭、購物、其他」，換三則訊息試試。未知訊息不保證會被歸到「其他」，仍要檢查。
