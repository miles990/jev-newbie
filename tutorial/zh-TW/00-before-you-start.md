# 第 0 課：開始之前

這份教程從日常訊息開始，不需要先會寫程式。前五課主要練習怎麼問問題；後面才進入批次資料與程式整合。

## 準備環境

先完成 [README 的準備步驟](../../README.zh-TW.md)：安裝 Node.js 20 以上、下載專案、在終端機進入專案資料夾，再設定 `TYPESAFE_API_KEY`。後面的指令都在這個資料夾執行。

```sh
node -v
node bin/jev.mjs --help
```

第一行應顯示 20 以上的版本；第二行顯示指令說明，不會呼叫 API。Windows 可用 PowerShell 執行本教程的 Node 指令。進階文件中的 Bash 腳本則需要 Bash，例如 Git Bash 或 WSL。

不用先裝 MCP、agent skill 或全域 `jev` 指令。本教程直接使用 `node bin/jev.mjs`，避免安裝路徑不同造成找不到指令。

## 三個詞

- **輸入（state）**：你想判斷的文字，也可以加上寄件者、自己的需求等背景。
- **問題**：你要它判斷什麼，例如「需要回覆嗎」。
- **機率與信心**：是非題的機率表示答案為「是」的可能性；單選與評分的 `confidence` 表示分布集中程度，不等於正確率。

每次問問題都會把輸入送到雲端並產生 API 用量。費用取決於請求大小與服務定價，不是固定的「每題價格」。本教程不要求你上傳私人訊息；可以先用附帶範例。

## 遇到問題

`node` 找不到：確認已安裝並重新開終端機。找不到 `bin/jev.mjs`：確認目前在專案資料夾。缺少 key：在目前視窗重新設定。想檢查連線可執行 `node bin/jev.mjs doctor`；它會做一次小型 API 判斷。
