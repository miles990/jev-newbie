# 第 3 課：一次問清楚一件事

「這則訊息重要嗎？」太模糊：你在意要不要回覆，還是今天要做事？問題越清楚，越容易檢查答案。

```sh
node bin/jev.mjs ask "這則訊息是否要求我回覆？" --text "明天上午停水，請今晚先準備用水，不必回覆。"
node bin/jev.mjs ask "這則訊息是否要求我在一天內採取行動？" --text "明天上午停水，請今晚先準備用水，不必回覆。"
```

同一則訊息可以「不用回覆」，但「需要行動」。如果合成「要回覆而且很急嗎」，一個數字就無法說明哪個條件成立。

必要時補充你對「是」與「否」的定義：

```sh
node bin/jev.mjs ask "需要我回覆嗎？" --yes "有明確問題或要求我確認" --no "只是告知，不要求回覆" --text "提醒你明天帶雨傘。"
```

可以用中文提問，也可以用英文；哪種較適合你的資料，應用相同測試集比較，不必一律翻成英文。

練習：挑一個含「而且」的問題，拆成兩題。先寫下你的預期，再執行比較。
