# 第 4 課：補上必要背景

同一句「明天記得帶球拍」，對要參加球賽的人和不參加的人，意義可能不同。模型不會知道你的行程，必須由你提供。

```sh
node bin/jev.mjs ask "我需要為這則訊息做準備嗎？" --text "明天記得帶球拍。"
node bin/jev.mjs ask "根據我的計畫，我需要為這則訊息做準備嗎？" --json '{"message":"明天記得帶球拍。","my_plan":"我已確認明天參加羽球活動，目前還沒整理裝備。"}'
```

`--json` 裡是一個有名稱的資料集合。`message` 放訊息，`my_plan` 放自己的情況；欄位名稱由你決定。JSON 的名稱與文字使用雙引號，整段在終端機中以單引號包起來。

加背景可能改變答案，但不保證一定改變，也不代表背景已經被查證。只放與問題有關的事實。

日期差、金額加總、到期與否，應由程式計算好再提供結果，例如 `due_today: true`；不要只丟日期並假設模型會算對。

練習：把 `my_plan` 改成「我已取消參加」，比較結果。不要同時更改問題與訊息，才看得出是哪個改動造成差異。
