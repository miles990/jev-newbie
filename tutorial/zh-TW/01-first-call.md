# 第 1 課：第一次判斷

你收到朋友的邀約，想知道是否需要回覆。先從一則你自己也能判斷的訊息開始。

```sh
node bin/jev.mjs ask "這則訊息是否需要我回覆？" --text "星期六晚上一起吃飯嗎？可以的話，明天前回我一下。"
```

`ask` 後面是問題；`--text` 後面是要判斷的文字。兩段都放在引號裡，避免空格被當成另一個參數。

## 怎麼讀結果

你會看到長條、百分比，以及 `yes`、`no` 或 `unsure`。百分比是答案為「是」的機率。工具把大於 65% 顯示為 `yes`，小於 35% 顯示為 `no`，其餘顯示 `unsure`。這是工具的示範門檻，並不是服務保證。

這則訊息明確要求回覆，合理的預期是偏向 `yes`；實際數字需要執行才知道，本頁沒有把示意值當成真實輸出。

## 換成自己的文字

```sh
node bin/jev.mjs ask "這則訊息是否需要我回覆？" --text "謝謝你，東西已收到，不用回覆。"
```

先只換文字，保留問題，方便理解差異。如果結果和你不同，先讀回問題與訊息，確認雙方在判斷同一件事。
